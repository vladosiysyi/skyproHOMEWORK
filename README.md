# PythonProject1

 Инициализации экземпляра класса
При инициализации экземпляра класса 
Product
 происходит обработка попытки создания товара с нулевым количеством.
Если пользователь попытается создать продукт с нулевым количеством, выбрасывается ошибка 
ValueError
 с сообщением «Товар с нулевым количеством не может быть добавлен».
 Метод подсчета среднего ценника всех товаров
Реализован метод подсчета среднего ценника всех товаров в классе Category, который складывает только цены (
self.price
) всех товаров категории и делит полученную сумму на количество товаров в категории.
В методе обработан случай, когда в категории нет товаров. В случае если такое происходит, возвращается ноль.
